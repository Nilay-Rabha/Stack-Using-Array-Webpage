
The Stack Using Array Visualizer is a simple, interactive web application developed using **HTML, CSS, and JavaScript**. It demonstrates how a stack data structure works and allows users to perform basic stack operations through an easy-to-use graphical interface.

A stack follows the **LIFO (Last In, First Out)** principle, meaning the last element inserted is the first element removed.

 Objectives

- Understand the implementation of a stack using an array.
- Visualize stack operations interactively.
- Learn the LIFO principle.
- Understand stack overflow and stack underflow.
- Practise front-end web development using HTML, CSS, and JavaScript.

 Features

- Push: Insert an element at the top of the stack.
- Pop: Remove the top element from the stack.
- Peek: View the top element without removing it.
- Display: View the current stack.
- Clear: Remove all elements from the stack.
- Live Visualization: See the stack update after each operation.
- Overflow Handling: Prevent insertion when the stack reaches its maximum capacity.
- Underflow Handling: Prevent deletion when the stack is empty.
- Responsive Design: Use the interface on desktop and mobile devices.
